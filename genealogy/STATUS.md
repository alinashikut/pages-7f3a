## 🔧 Технические Детали

### Использованные технологии
- **Node.js** с Playwright для браузерной автоматизации
- **HTTPS** с игнорированием самоподписанных сертификатов
- **Git** для версионирования результатов
- **JSON** для структурирования данных

### Ключевые скрипты
```bash

node final-extraction.js

# Расширенный поиск
node advanced-search.js

# Автоматическое извлечение (повышенная сложность)
node extract-cases.js
```
