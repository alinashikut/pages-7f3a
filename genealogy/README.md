# Семейный архив - Генеалогические исследования

## 📖 Описание проекта

Этот проект посвящен автоматизированному сбору и анализу генеалогических данных из электронного каталога архивов Брянской области (ГАБО ЭЧЗ).

**Цель:** Реконструкция родословной семей Хряпчиных и Хроменков из Брянской области (деревни Кистер и Гудовка).

## 🎯 Исследуемые фамилии

### Основные варианты:
- **Хряпчин** / Хрепчин / Хрипчин
- **Хромяк** / Хроменко / Хроменок

## 🔧 Автоматизация

### Использованные технологии:
- **Playwright** - браузерная автоматизация для веб-скрейпинга
- **Node.js** - обработка и парсинг данных
- **Git** - версионирование результатов

### Основные скрипты:
- `find-families.js` - поиск фамилий в делах фонда 542
- `extract-cases.js` - извлечение содержимого дел
- `final-extraction.js` - финальное извлечение и анализ

## 📝 Процесс исследования

1. **Авторизация** в ГАБО ЭЧЗ

3. **Локализация** интересующих дел (486, 51, 122, 156, 418, 32)
4. **Извлечение** информации о семьях
5. **Анализ** и структурирование полученных данных
6. **Документирование** результатов
